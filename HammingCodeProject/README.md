# Hamming Code in C++

## Description

This project implements the Hamming Code algorithm for:

- Encoding a binary message
- Error detection
- Message verification

## Input Message

1010101000011010

## Encoded Message

111101001010000011010

## Features

- Hamming Code generation
- Single-bit error detection
- Message validation
- Simple test routine

## Compilation

```bash
g++ main.cpp -o hamming
```

## Run

```bash
./hamming
```
